# 第三方开源仓库与公开数据

演示不安装这些扫描器。内置匹配直接调用 OSV、KEV 和 EPSS。本机若存在 Trivy、Grype、Syft 或 osv-scanner，报告里会少一条「未检测到」的提示；当前版本还不解析它们的 JSON。

| 项目 | 链接 | 在本工具中的位置 |
| --- | --- | --- |
| OSV.dev | https://github.com/google/osv.dev | 在线查询 `https://api.osv.dev/v1/query`，快照落在 `vulnguard/data/osv_snapshot.json` |
| OSV Schema | https://github.com/ossf/osv-schema | 采用 introduced / fixed / last_affected 的区间语义 |
| osv-scanner | https://github.com/google/osv-scanner | 预留的第二意见，未内置调用 |
| NVD | https://nvd.nist.gov/ | 策展条目的 CVSS 与详情链接；CVSS v3 基础分在 `vulnguard/cvss.py` 按公开规范计算 |
| CISA KEV | https://github.com/cisagov/kev-data | 目录原文 `https://www.cisa.gov/sites/default/files/feeds/known_exploited_vulnerabilities.json` |
| EPSS | https://github.com/cyentia/epss-api | `https://api.first.org/data/v1/epss`，说明见 https://www.first.org/epss |
| Trivy | https://github.com/aquasecurity/trivy | 文档中的后续扫描器，适合镜像和发行版包 |
| Syft | https://github.com/anchore/syft | 文档中的后续 SBOM 工具 |
| Grype | https://github.com/anchore/grype | 文档中的后续漏洞匹配器 |
| FastAPI | https://github.com/fastapi/fastapi | Web 界面 |
| Uvicorn | https://github.com/encode/uvicorn | 界面进程 |
| Jinja2 | https://github.com/pallets/jinja | 页面模板 |
| packaging | https://github.com/pypa/packaging | PyPI 版本比较 |
| Redis 安全公告 | https://github.com/redis/redis/security | CVE-2022-0543 的 GHSA 与上游版本背景 |
| Log4j 安全页 | https://logging.apache.org/log4j/2.x/security.html | log4j-core 的修复下限 |

公开漏洞数据的版权和许可以各数据源为准。本仓库的代码是笔试作品。
